# CRAFT — Digital Product School

Стартовая публичная страница CRAFT на Next.js 14, React 18 и TypeScript.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Проверка production-сборки

```bash
npm run build
```

## Текущий статус

- [x] Адаптивная публичная главная страница
- [x] Базовые метаданные и структура Next.js App Router
- [ ] Реальная форма заявок и серверная обработка
- [ ] База данных и админ-панель
- [ ] Авторизация и личный кабинет
- [ ] Учебная платформа, прогресс и материалы
- [ ] Платежи

CTA пока использует mailto-ссылку-заглушку. Это не production-форма. Не добавляйте секреты в репозиторий. Перед публичным запуском нужны проверка сборки, тестирование, настройка домена и реальный канал приёма заявок.

## Принципы продукта

CRAFT — практическая программа создания собственного цифрового продукта: исследование проблемы и спроса, проектирование, MVP, запуск, первые пользователи и монетизация. AI/no-code — инструменты, а не само обещание программы.
