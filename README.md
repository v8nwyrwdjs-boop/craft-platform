# CRAFT — Digital Product School

CRAFT — практическая школа создания цифрового бизнеса. Ученик выбирает направление или бизнес-концепцию, обсуждает её с наставником, проверяет спрос и создаёт собственный цифровой продукт.

## Технологии
- Next.js 14 App Router
- React 18
- TypeScript
- CSS (адаптивный интерфейс)

## Локальный запуск
```bash
npm install
npm run dev
```
Откройте http://localhost:3000.

## Текущие разделы
- Главная: два пути входа в CRAFT.
- /directions: каталог бизнес-направлений.
- /products: каталог демонстрационных бизнес-концепций.

## Аккаунты и личный кабинет
- /register: создание аккаунта по email и паролю.
- /login: вход.
- /dashboard: личный кабинет и список проектов.
- Supabase Auth + SSR cookies; схема профилей и проектов — supabase/schema.sql.
- Регистрация бесплатная и отделена от доступа к платному обучению.

Для включения авторизации создайте проект Supabase, примените SQL из supabase/schema.sql, скопируйте .env.example в .env.local и заполните URL, anon key и URL сайта. Без этих настроек формы покажут понятное сообщение о необходимости конфигурации.

Подробности: docs/accounts-and-onboarding.md.

## Статус разработки
Текущая работа находится в ветке `feature/business-catalogs`. Каталоги и главная — frontend-прототипы с демонстрационным содержанием.

Пока НЕ реализованы:
- серверная обработка заявок;
- база данных и CMS;
- авторизация и личные кабинеты;
- закрытый учебный контент и проверка доступа;
- задания, отправка работ и обратная связь;
- админ-панель;
- платежи и управление заказами.

CTA на страницах пока ведут на mailto-заглушку. Это не production-приём заявок. Не добавляйте секреты в репозиторий. Перед публичным запуском нужны тестирование, проверка безопасности, юридические документы и настройка реального канала заявок.

## Продуктовые принципы
- Два каталога — две точки входа в один учебный маршрут.
- Бизнес-концепции — гипотезы для исследования, не гарантированно прибыльные бизнесы.
- Ученик может обсуждать концепцию с наставником, менять нишу или отказаться от идеи.
- Сначала проблема и проверка спроса, затем масштабная разработка.
- Marketplace внешних наставников и конструктор сторонних школ не входят в CRAFT 1.0.
