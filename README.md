# CRAFT — Digital Product School

CRAFT — практическая школа создания цифрового бизнеса. Пользователь регистрирует аккаунт, выбирает направление или бизнес-концепцию, сохраняет собственный проект, проверяет спрос и проходит учебный маршрут с поддержкой наставника.

## Технологии
- Next.js 14 App Router
- React 18 + TypeScript
- Supabase Auth + Supabase SSR
- PostgreSQL + Row Level Security
- GitHub Actions build workflow

## Локальный запуск
1. npm install
2. Скопировать .env.example в .env.local.
3. Заполнить переменные Supabase.
4. npm run dev.
Откройте http://localhost:3000.

## Основные маршруты
- / — публичная главная.
- /directions — каталог направлений.
- /directions/[slug] — детальная страница направления.
- /products — каталог бизнес-концепций.
- /products/[id] — детальная страница концепции и сохранение в проекты.
- /register, /login — регистрация и вход.
- /forgot-password, /account/reset-password — восстановление доступа.
- /dashboard — личный кабинет и проекты ученика.
- /learn, /learn/[module] — программа и учебные модули (доступ после зачисления).

## Подключение Supabase
1. Создать проект Supabase.
2. Выполнить SQL из supabase/schema.sql в SQL Editor.
3. Скопировать .env.example в .env.local.
4. Заполнить NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, NEXT_PUBLIC_SITE_URL.
5. В Supabase Auth настроить Site URL и Redirect URLs: локальный http://localhost:3000/auth/callback и production callback.
6. Настроить SMTP и email confirmation для production.

Регистрация бесплатная и отделена от доступа к платной программе. Чтобы вручную зачислить ученика после проверки оплаты/условий, администратор с безопасным доступом может создать запись в public.enrollments со статусом active. Не открывать insert в enrollments для обычных пользователей. Сервисный ключ никогда не добавлять в браузер или Git.

## База данных и безопасность
- profiles — профиль пользователя.
- student_projects — проекты ученика.
- enrollments — зачисление в программу.
- lesson_progress — прогресс по урокам.
- assignment_submissions — ответы учеников на практические задания.
- mentor_feedback — обратная связь наставника (пока без интерфейса управления).
- Для пользовательских таблиц включён RLS; проекты и прогресс доступны только владельцу.
- Доступ к урокам проверяется на сервере и дополнительно ограничен RLS.
- middleware.ts обновляет сессию и защищает маршрут кабинета.

## Текущие ограничения
- Supabase project, SMTP и реальные env-переменные не подключены; поэтому реальные регистрации ещё не активированы.
- Нет полноценной административной панели и интерфейса управления зачислениями.
- Учебная программа — стартовая структура и учебные заготовки, требует методической редакции.
- Отправка текстовых ответов на задания реализована; интерфейс проверки наставником и комментарии ещё не созданы.
- Нет файлового хранилища и загрузки вложений.
- Нет платежей, биллинга, production deployment и юридических документов.
- Не подтверждена успешная сборка в CI для последнего набора изменений.

## Принципы
- Два каталога ведут к единому учебному маршруту.
- Концепции — гипотезы, а не обещание прибыли.
- Ученик может сменить идею в процессе.
- Сначала проблема и проверка спроса, затем масштабная разработка.
- Marketplace внешних наставников отложен.
