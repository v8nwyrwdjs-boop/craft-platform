## Инженерные правила

- Не коммитить секреты, ключи и персональные данные.
- Валидировать входные данные на сервере.
- Проверять права на каждом защищённом endpoint и в RLS.
- Зачисление не может создавать обычный пользователь.
- Платёжный статус должен определяться только доверенным серверным событием провайдера.
- Не подключать платные сервисы и не запускать production без явного согласования.
