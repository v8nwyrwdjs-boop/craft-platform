## Находки

**F1. Высокая, исправлено (`5383dce`).** Защита от открытого редиректа `safeInternalPath` пропускала значения вроде `/..//evil.example` и `/%2e%2e//evil.example`: парсер URL убирает точечные сегменты, и результат превращался в `//evil.example`, а браузер читает такой адрес как внешний. Затронуты `signIn` (`redirect(next)`) и `/auth/callback?next=`. Воспроизведено запуском функции, исправлено повторной проверкой после нормализации. Тест красный на старой функции и зелёный на новой; добавлен перебор 2 801 входа, результат которого не может начинаться с `//`.

**F2. Средняя, нужно решение владельца.** В репозитории нет `package-lock.json`, CI делает `npm install`. Версии внутри кареток могут поменяться между сборками, а `npm audit` в CI проверяет не то дерево, которое попадёт в продакшен. Правила AGENTS.md запрещают трогать манифесты без явной необходимости, поэтому не менял. Предложение: `npm install --package-lock-only`, закоммитить файл, в CI заменить `npm install` на `npm ci`.

**F3. Средняя, закрывается в v2.** Строка `@import` Google Fonts в `globals.css` блокировалась собственной CSP (`font-src 'self' data:`): страницы показывались запасным шрифтом, в консоли были ошибки. В v2 шрифты лежат в `public/fonts`.

**F4. Низкая, закрывается в v2.** `/favicon.ico` отдавал 404.

**F5. Низкая, исправлено.** `.gitignore` не покрывал `*.tsbuildinfo`, `.vercel`, `.env.*.local`, `coverage`.

**F6. Низкая, принято.** CSP содержит `'unsafe-inline'` для скриптов и стилей: он нужен встроенным скриптам Next. Политика с nonce сделала бы все страницы динамическими. Остальные заголовки (HSTS, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`) на месте. Заголовок HSTS с `preload` стоит учесть владельцу при подключении своего домена.

**F7. Низкая, закрывается в v2.** `student_projects.origin_slug` проверяется только по маске: сохранить можно несуществующее направление. В v2 значение сверяется с каталогом. Лимита числа проектов на пользователя нет; он требует миграции базы, которую применяет владелец.

**F8. Рекомендация без правки.** Для политик RLS полезны индексы по `student_id` в `student_projects`, `assignment_submissions`, `mentor_feedback`. Сейчас данных мало, на скорость не влияет. Миграцию не добавлял: применять её может только владелец проекта Supabase.

**F9. Принято к сведению.** Серверные действия Next проверяют Origin запроса по документации фреймворка; запуском здесь не проверялось, потому что нет подключённого проекта Supabase.

Проверено и замечаний нет: секретов в отслеживаемых файлах нет (`.env.example` содержит заглушки); `dangerouslySetInnerHTML`, `innerHTML`, `eval`, `target="_blank"` не используются; `return_to` сверяется с белым списком масок; `moduleSlug` в редиректах проходит `isValidLessonForModule`; ввод в действиях ограничен по длине и формату.
